# Convención de Commits (Conventional Commits)

Estructura formal para comunicar intención y facilitar changelogs automatizados.

## Formato Estándar
`<tipo>(<alcance opcional>): <descripción imperativa corta>`

## Tipos Principales
- `feat`: Nueva funcionalidad o capacidad para el usuario.
- `fix`: Corrección de un defecto o bug.
- `docs`: Modificaciones exclusivas de documentación.
- `refactor`: Cambio de código que ni arregla bugs ni añade features.
- `test`: Añadir o corregir pruebas unitarias o de integración.
- `chore`: Tareas de mantenimiento, dependencias o herramientas de build.

## Reglas de Redacción
- Verbo en tiempo presente imperativo (ej: `add`, `fix`, `update`).
- Sin punto final en el título y en minúsculas.
