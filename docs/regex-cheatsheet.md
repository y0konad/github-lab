# Expresiones Regulares (RegEx) Prácticas

Patrones cotidianos y conceptos fundamentales para validación y búsqueda.

## Metacaracteres y Cuantificadores
- `^` y `$`: Coincidencia con inicio y final de línea.
- `\d` / `\D`: Dígitos numéricos / cualquier carácter que no sea dígito.
- `+` (uno o más), `*` (cero o más), `?` (cero o uno / opcional).
- `{n,m}`: De n a m repeticiones.

## Grupos y Búsqueda
- `(abc)`: Grupo de captura.
- `(?:abc)`: Grupo de no captura (para optimizar parsing).
